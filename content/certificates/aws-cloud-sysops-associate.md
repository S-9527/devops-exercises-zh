## AWS 云系统运营管理助理

您可以找到考试所需了解的摘要 [这里](https://aws.amazon.com/certification/certified-sysops-admin-associate)

<a name="who-should-take-this-exam"></a>
### <b>  谁应该参加这项考试？ </b>
<br>
AWS 认证 SysOps 管理员 - 助理适用于担任云运营角色的系统管理员，以验证技术技能。 

<summary>在参加本次考试之前，我们建议您：</summary><br><b>

  * 至少一年的实践经验 AWS 技术
  * 拥有部署、管理和操作工作负载的经验 AWS 以及实施安全控制和合规性要求
  * 熟悉使用这两种方法 AWS 管理控制台和 AWS 命令行界面（CLI)
  * 的理解 AWS 架构良好的框架以及 AWS 网络和安全服务
</b>
