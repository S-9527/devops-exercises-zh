<a name="how-do-i-become-a-better-devops-engineer"></a>
### 如何成为更好的 DevOps Engineer？

这是一个很好的问题。<br>
这个问题我没有绝对确定的答案，自己也会不时重新思考。我认为有帮助的是：

  * 练习 - 在实践中练习 DevOps，是成为 DevOps Engineer 的主要方式
  * 阅读 - 博客、书籍，以及任何能够扩展 DevOps 或相关主题知识的内容
  * 参与 - DevOps 社区里有很多高质量讨论。我个人喜欢 [Reddit DevOps community](https://www.reddit.com/r/devops)，在那里可以学到很多不同主题的内容
  * 分享 - 这也是我创建这个项目的原因之一。最初目标是帮助别人，但很快它也变成了让我自己学到更多的方式。通过提出问题，你也会更好地理解某个主题。可以试试看：选定一个主题，然后尝试设计一些问题，用来测试别人对这个主题的掌握程度

<a name="what-are-the-top-devops-skills-required-for-being-a-devops-engineer"></a>
### 成为 DevOps Engineer 最需要哪些技能？

这是一个很难回答的问题，原因是如果你问 20 个不同的人，你可能会得到至少 10 个不同的答案，但我认为以下是当今常见的答案：

* OS - DevOps 要求您充分了解操作系统概念。所需的级别主要取决于公司，但我认为应该是相同的级别。您应该了解操作系统如何工作、如何排除和调试问题等。
* 编程是一部分 DevOps。级别再次取决于公司。有些需要您了解基本的脚本编写水平，而另一些则要求您深入了解常见算法、数据结构、设计模式等。
* Cloud 和 Containers - 虽然不是所有公司或岗位都 100% 必需，但这项技能的重要性每年都在上升，很多岗位都会要求。具体包括 AWS/Azure/GCP、Docker/Podman、Kubernetes 等
* CI/CD - 能够回答类似“为什么需要 CI/CD？”和“有哪些 CI/CD 的方式与模型？”的问题。最终，你还应该使用自己熟悉的工具，实际练习搭建这类流程和 workflow

<a name="why-cant-i-add-installation-questions"></a>
### 为什么我无法添加安装问题？

一般来说，我更喜欢添加到此存储库中的问题对用户具有一定的教育价值。要么是关于某个概念，要么是一个非常普遍的问题，但它会让用户研究某个主题，并最终让他更熟悉它的一些核心概念。<br>
我知道，截至今天，本存储库中的每个问题并非都是如此（例如有关特定命令的问题），但这绝对是值得追求的。

我认为所谓的“安装问题”几乎没有任何价值。假设我问你“如何安装 Jenkins？”。我应该从你的回答中得出你熟悉它是什么的结论吗 Jenkins 和/或它是如何工作的？换句话说，了解如何安装是否有价值？ Jenkins？我认为，不。

<a name="why-some-questions-repeat-themselves"></a>
### 为什么有些问题会重复出现？

如果您看到两个相同的问题，那就是一个错误。<br>
如果您看到两个类似的问题，那就是一个功能：D（=这是故意的）

例如：

1. 什么是水平缩放？
2. 向池中添加额外实例以处理扩展的行为称为 ________ 扩展

你是对的，两者都询问了水平缩放，但每个问题都是从不同的角度完成的，此外，我确实相信重复可以帮助你以一种不固定于所问方式的方式学习一些东西，而是你理解概念本身。
