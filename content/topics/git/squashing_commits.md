## Git - Squashing Commits

<a name="objective"></a>
### 目的

了解如何压缩提交

<a name="instructions"></a>
### 使用说明

1. 在 git 存储库中，创建一个内容为“Mario”的新文件并创建一个新的提交
2. 更改您刚刚创建的文件的内容，使内容为“Mario & Luigi”并创建另一个提交
3. 验证您有两个单独的提交
4. 将最新的两次提交压缩为一次提交

<a name="after-you-complete-the-exercise"></a>
### 完成练习后

回答以下问题：

* 压缩提交的原因是什么？
* 是否可以压缩 2 次以上的提交？
