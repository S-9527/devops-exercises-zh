## Git 提交01

<a name="objective"></a>
### 目的

了解如何提交更改 Git 存储库

<a name="instructions"></a>
### 使用说明

1. 创建一个新目录
2. 使其成为 git 存储库
3. 创建一个名为的新文件 `file` 内容为“你好提交”
4. 提交您的新文件
5. 运行 git 命令来验证您的提交是否已记录

<a name="after-you-complete-the-exercise"></a>
### 完成练习后

回答以下问题：

* 提交有什么好处？
* 是否有另一种方法来验证提交是否已创建？
