## Git 提交01

<a name="objective"></a>
### 目的

了解如何与 Git 分支机构

<a name="instructions"></a>
### 使用说明

1. 接载时间为 Git 至少有一次提交的存储库（或创建一个新的存储库）
2. 创建一个名为“dev”的新分支
3. 修改存储库中的文件之一
4. 创建一个新的提交
5. 验证您创建的提交仅在“dev”分支中

### 完成练习后
