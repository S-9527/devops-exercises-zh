# Elasticsearch, Kibana 和 AWS

您的任务是构建一个elasticsearch集群以及 Kibana 以下云之一上的仪表板：

* AWS
* OpenStack
* Azure
* GCP

您必须详细描述（最好带有一些图纸）您将如何设置它。
请详细描述：

- 如何放大或缩小
- 如何快速（不到 20 分钟）配置集群
- 如何应用访问控制的安全策略
- 如何将日志从应用程序传输到 ELK
- 如何处理在不同地区运行的多个应用程序

<a name="solution"></a>
# 解决方案

这是众多可能的解决方案之一。该解决方案很大程度上依赖于 AWS.

* 创建一个 VPC 带有子网，这样我们就可以放置 Elasticsearch 仅内部环境中的节点。
  如果需要，我们还将设置 NAT 供公众访问。 

* 创建一个 IAM 访问集群的角色。另外，创建一个单独的角色用于管理员访问。

* 为了快速配置解决方案，我们将直接使用elasticsearch服务 AWS 用于生产部署。
  这样我们也覆盖了多个AZ。至于身份验证，我们要么使用 Amazon cognito，要么使用组织 LDAP 服务器。

* 要传输数据，我们必须在实例上安装logstash代理。代理将负责
  用于将数据推送到elasticsearch。

* 为了进行监控，我们将使用：

    * 云监控监控集群资源利用率
    * 云指标仪表板

* 如果需要从多个区域访问，我们会将所有数据传输到 S3 这将使我们能够查看数据
  来自不同地区并将其整合到一个仪表板中
