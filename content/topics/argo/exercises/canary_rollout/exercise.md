# Argo Rollouts - 金丝雀

<a name="requirements"></a>
## 要求

1. 跑步 Kubernetes 集群
2. Argo Rollouts CLI
3. 以特定版本部署的应用程序

<a name="objectives"></a>
## 目标

1. 安装 Argo Rollouts控制器
2. 编写使用金丝雀 Rollout策略的发布清单并应用它
   1. 将其设置为 3 个副本
   2. 禁用自动促销
3. 检查Rollout 列表
4. 以您喜欢的任何方式发布应用程序的新版本
   1. 检查发布的状态
