# 应用程序创建

<a name="requirements"></a>
## 要求

1. 确保你有一些存储库 Kubernetes 体现
2. 确保您有一个 Kubernetes 集群运行 ArgoCD 已安装

<a name="objectives"></a>
## 目标

1. 使用 CLI 或 UI，创建一个具有以下属性的新应用程序：
   1. 应用程序名称：应用程序演示
   2. 项目：应用程序项目
   3. 存储库 URL：带有一些 k8s 清单的存储库
   4. 命名空间：默认
2. 验证应用程序是否已创建
3. 同步应用程序
4. 验证 Kubernetes 资源已创建
5. 删除应用程序
