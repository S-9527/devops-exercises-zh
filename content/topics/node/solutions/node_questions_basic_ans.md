# ANSWERS 

1. Node.js 是一个开源、跨平台的 JavaScript 运行时环境，允许开发人员构建服务器端和网络应用程序。
2. Nodejs 是一种单线程语言。它一次处理一项操作。
3. Node.js 通过执行来工作 JavaScript Web 浏览器之外的运行时环境中的代码。 
4. Node.js 通过执行来工作 JavaScript Web 浏览器之外的运行时环境中的代码。主要用于项目的性能和可扩展性
5. 父进程管理子进程但不依赖clid进程并行运行
6. 主要分为三个模块 
    1. 核心模块 - fs , require
    2. 本地模块 - 类似于我们创建的函数，并从一个文件导出或导入到另一个文件
    3. 第三方模块 - 例如 npm pacakages，我们安装它来完成特定类型的工作
7. NPM （Node Pacakage Manager）用于安装、管理和共享 JavaScript 包和依赖项。
8. pacakage.json 和 pacakage-lock.json 之间的区别
   1.pacakage.json - 包含项目的元数据和依赖项
   2.pacakage-lock.json - 锁定已安装依赖项的版本
