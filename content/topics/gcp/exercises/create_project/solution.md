# 创建一个项目

<a name="objectives"></a>
## 目标

1. 创建一个具有唯一名称的项目

<a name="solution"></a>
## 解决方案

<a name="console"></a>
### 控制台

1. 单击顶部栏中的“新建项目”（如果您已有项目，则单击项目名称，然后单击“新建项目”）或在搜索栏中插入“创建项目”。
2. 插入全局唯一的项目名称
3. 可选择选择一个组织
4. 可以选择将其放在特定文件夹下
5. 点击“创建”:)
