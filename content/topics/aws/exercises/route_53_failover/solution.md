## AWS Route 53 - Failover

<a name="requirements"></a>
### 要求

一个跑步 EC2 为其定义了健康检查的 Web 实例 Route 53

<a name="objectives"></a>
### 目标

1. 创建一个故障转移记录，如果运行状况检查未通过，该记录将故障转移到另一条记录
  1. 确保 TTL 是 30
  2. 将故障转移记录与您的健康检查相关联

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 Route 53 服务
2. 单击左侧菜单中的“托管区域”
3. 单击您的托管区域
4. 点击“已创建记录”
5. 在记录名称中插入“故障转移”并将记录类型设置为 A
6. 插入 IP 你的实例的
7. 设置路由策略为故障转移
8. 套装 TTL 至 30
9. 与健康检查关联
10. 添加与前一条具有相同属性的另一条记录
11. 点击“创建记录”
12. Go 给你的 EC2 实例并编辑其安全组以删除 HTTP 规则
13. 使用您的网络应用程序，如果您打印实例的 hotsname，那么您会注意到，已执行故障转移并执行不同的操作 EC2 使用实例
