## AWS EC2 - EBS 快照

<a name="requirements"></a>
### 要求

EBS 体积

<a name="objectives"></a>
### 目标

A. 创建一个快照 EBS 体积
B. 验证快照是否已创建
C. 将数据移动到另一个区域
D. 在不同的目录中创建一个卷 AZ

<a name="solution"></a>
### 解决方案

A.
1. Go 到 EC2 服务
2. 单击“弹性块存储”下的“卷”
3. 右键单击所选卷 -> 创建快照
4. 插入描述并单击“创建快照”

b.
1. 单击“弹性块存储”下的“快照”
2. 您应该会看到您创建的快照

C.
1. 选择快照并单击“操作”->“复制”
2. 选择要将快照复制到的区域

D .
1. 选择快照并单击“操作”->“创建卷”
2. 选择不同的 AZ
3. 点击“创建卷”
