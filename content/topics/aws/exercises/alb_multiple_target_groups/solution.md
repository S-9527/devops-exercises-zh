## AWS ELB - ALB 多个目标群体

<a name="requirements"></a>
### 要求                   

两个 EC2 具有简单 Web 应用程序的实例，该应用程序显示带有字符串“嘿，这是我， `<HOSTNAME>`!"
一 EC2 具有简单 Web 应用程序的实例，该应用程序在端点 /test 下显示带有字符串“嘿，这只是一个测试...”的网页

<a name="objectives"></a>
### 目标

1. 为您拥有的两个实例创建一个应用程序负载均衡器，具有以下属性
  1. 健康阈值：3
  2. 不健康阈值：3
  3. 间隔：10秒
2. 为第三个实例创建另一个目标组
  1. 流量应根据“/test”路径转发到该组

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 EC2 服务
2. 单击左侧菜单中“负载平衡”下的“负载平衡器”
3. 点击“创建负载均衡器”
4. 选择“应用程序负载均衡器”
5. 插入名称 LB
6. 选择一个 AZ 你想要的地方 LB 进行操作
7. 选择安全组
8. 在“侦听器和路由”下，单击“创建目标组”并选择“实例”
  1. 提供目标组的名称
  2. 将健康阈值设置为 3
  3. 将不健康阈值设置为 3
  4. 将间隔设置为 10 秒
  5. 单击“下一步”，然后从您创建的三个实例中选择两个
  6. 点击“创建目标组”
9. 刷新目标组并选择您刚刚创建的目标组
10. 单击“创建负载均衡器”并等待其配置

11. 在左侧菜单中，单击“负载平衡”下的“目标组”
12. 点击“创建目标组”
13. 将其设置为与之前的目标组相同的属性，但这一次，添加未包含在之前的目标组中的第三个实例
14. Go 回到你的 ALB 然后在“侦听器”下单击当前侦听器下的“编辑规则”
  1. 添加一条规则，其中如果路径是“/test”，则流量应转发到您创建的第二个目标组
  2. 点击“保存”
15. 测试一下，进入浏览器，插入地址，并在地址中添加“/test”
