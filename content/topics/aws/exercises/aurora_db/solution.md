## AWS 数据库 - 极光 DB

<a name="objectives"></a>
### 目标

1. 创建具有以下属性的 Aurora 数据库
  * 版本： MySQL
  * 实例类型：db.t3.small
  * 不同的读取器节点 AZ
  * 应启用公共访问
  * 端口应设置为 3306
  * DB 名称：'db'
  * 备份保留：10天

2. 您的实例有多少个 DB 簇有?

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 RDS 服务
2. 单击左侧菜单中的“数据库”，然后单击“创建数据库”按钮
3. 选择“标准创建”
4. 选择“极光 DB"
5. 选择“MySQL“版本”和“已配置”作为容量类型
6. 选择“单主”
7. 指定凭据（主用户名和密码）
8. 选择 DB 实例类型：Burstable 类，db.t3.small
9. 选择“在不同的位置创建 Aurora 副本或读取器节点” AZ"
10. 选择默认值 VPC 和子网
11. 勾选“是”以进行公共访问
12. 数据库端口应该是3306
13. 对于身份验证，选择“密码和 IAM 数据库验证”
14. 将初始数据库名称设置为“db”
15. 将备份保留期增加至 10 天
16. 单击“创建数据库”按钮

1. 两个实例 - 一名读者和一名作者
