## AWS EC2 - Placement Groups          

<a name="objectives"></a>
### 目标                      

A. 创建归置组。它应该是一个低延迟网络。确保启动一个实例作为此置放群组的一部分。
B. 创建另一个置放群组。这个时候高可用是优先考虑的

<a name="solution"></a>
### 解决方案                        

A.
1. Go 到 EC2 服务
2. 单击“网络与安全”下的“置放群组”
3. 点击“创建置放群组”
4. 为其命名并选择“集群”放置策略，因为要求是低延迟网络
5. 点击“创建群组”
6. Go 到“实例”并单击“启动实例”。选择您想要的任何属性，只需确保选中“将实例添加到置放群组”并选择您创建的置放群组

b.
1. Go 到 EC2 服务
2. 单击“网络与安全”下的“置放群组”
3. 点击“创建置放群组”
4. 为其命名并选择“Spread”放置策略，因为要求将高可用性作为首要任务
5. 点击“创建群组”
