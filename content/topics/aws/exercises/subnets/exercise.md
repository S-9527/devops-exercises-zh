## AWS VPC - Subnets

<a name="requirements"></a>
### 要求

1. 新创建的单曲 VPC
2. 具有两个以上可用区的区域

<a name="objectives"></a>
### 目标

1. 在新创建的子网中创建子网 VPC
  1. CIDR：10.0.0.0/24
  2. 名称：新子网1
2. 创建额外的子网
  1. CIDR：10.0.1.0/24
  2. 名称：新子网2
  3. 不同 AZ 与之前的子网相比
3. 创建额外的子网
  1. CIDR：10.0.2.0/24
  2. 名称：NewSubnet3
  3. 不同 AZ 与之前的子网相比
