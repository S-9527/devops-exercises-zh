## AWS EC2 - 安全组

<a name="requirements"></a>
### 要求 

对于本练习，您需要：

1. EC2 带有 Web 应用程序的实例
2. 安全组入站规则允许 HTTP 交通

<a name="objectives"></a>
### 目标

1. 列出您所使用区域的账户中的安全组
2. 删除 HTTP 入站流量规则
3. 您仍然可以访问该应用程序吗？你看到/得到什么？
4. 添加回规则
5. 您现在可以访问该应用程序吗？
