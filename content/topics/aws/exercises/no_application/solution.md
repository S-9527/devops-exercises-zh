## 没有申请:'(

<a name="objectives"></a>
### 目标

解释以下问题的可能原因：

1. 尝试访问正在运行的应用程序时出现“超时” EC2 实例
2. 收到“连接被拒绝”错误

<a name="solution"></a>
### 解决方案

1. “超时”可能是由于以下原因之一造成的：

  * 安全组不允许访问
  * 没有主机（是的，我知道。这不是首先要检查的事情，但......）
  * 操作系统防火墙阻止流量

2. “连接被拒绝”可能是由于以下原因之一造成的：

  * 应用程序未正确启动或存在一些问题（未侦听指定端口）
  * 防火墙以拒绝响应而不是丢弃数据包
