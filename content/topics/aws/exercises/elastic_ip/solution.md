## AWS EC2 - Elastic IP

<a name="requirements"></a>
### 要求

* 一个带有公有 IP 的 EC2 实例（没有 Elastic IP）

<a name="objectives"></a>
### 目标

1. 写下大众 IP 你的 EC2 某处实例并停止和启动该实例。公众是否 IP 地址是一样的吗？为什么？
2. 处理这种情况，以便您拥有相同的公网 IP 即使在停止并启动实例之后

<a name="solution"></a>
### 解决方案

1. Go 到 EC2 服务->实例
  1. 写下当前公网 IP 地址
  2. 点击“实例状态”->停止实例->停止
  3. 点击“实例状态”->启动实例
  4. 是的，公网 IP 地址已更改
2. 让我们使用弹性 IP 地址
  1. 在 EC2 服务，在“网络和安全”下单击“Elastic IP"
  2. 单击“分配弹性 IP 地址”按钮
  3. 确保选择“Amazon IPv4 地址池”并单击“分配”
  4. 单击“操作”，然后单击“关联弹性” IP 地址”
    1. 选择“实例”，选择您的实例并提供其私有实例 IP 地址
    2. 点击“关联”
  5. 现在，如果我们返回实例页面，我们可以看到它正在使用 Elastic IP 作为其公众地址 IP

注意：要删除它，请使用“取消关联”选项，并且不要忘记同时释放它，这样您就不会被计费。
