# 创建存储桶

<a name="objectives"></a>
## 目标

1. 创建以下存储桶：
   1. 私有存储桶
      1. eu-west-2 区域
      2. 将单个文件上传到存储桶。任何文件。
   2. 公共存储桶
      1. eu-west-1 区域
      2. 应启用版本控制

<a name="solution"></a>
## 解决方案

<a name="console"></a>
### 控制台

对于第一个桶：

1. Go 到 S3 服务于 AWS 控制台。如果不在“存储桶”页面中，请单击左侧菜单中的“存储桶”
2. 点击“创建存储桶” 
3. 为您的存储桶指定一个全球唯一的名称
4. 选择区域“eu-west-2”
5. 点击“创建存储桶”
6. 单击存储桶名称
7. 在“对象”下单击“上传”->“添加文件”->选择要上传的文件->单击“上传”

对于第二个桶：

1. Go 到 S3 服务于 AWS 控制台。如果不在“存储桶”页面中，请单击左侧菜单中的“存储桶”
2. 点击“创建存储桶” 
3. 为您的存储桶指定一个全球唯一的名称
4. 选择区域“eu-west-1”
5. 确保取消选中“私人存储桶”复选框以将其公开
6. 确保选中“存储桶版本控制”的启用框
7. 点击“创建存储桶”
