## AWS Route 53 - Health Checks

<a name="requirements"></a>
## 要求

不同可用区的 3 个 Web 实例。

<a name="objectives"></a>
## 目标 

1. 为每个实例创建具有以下属性的运行状况检查：
  1. 以 AZ 实例所在的位置
  2. 失败阈值应为 5

2. 编辑您的实例之一的安全组并删除 HTTP 规则。
  1. 它是否改变了健康检查的状态？

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 Route 53
2. 单击左侧菜单中的“健康检查”
3. 点击“创建健康检查”
4. 插入名称：us-east-2
5. 监控什么：端点
6. 插入 IP 实例的地址
7. 如果您的 Web 实例支持该端点，请插入端点 /health
8. 在高级配置中，将故障阈值设置为 5
9. 单击“下一步”，然后单击“创建健康检查”
10. 对您拥有的其他两个实例重复步骤 1-9

1. Go 到您的实例之一的安全组
2. 点击“操作”->编辑入站规则->删除 HTTP 基于规则
3. Go 返回健康检查页面，几秒钟后您应该看到状态变为“不健康”
