## AWS EC2 - Spot Instances                                                                                                                                                  
<a name="objectives"></a>
### 目标             

A. 使用具有以下属性的 Spot 请求创建两个 Spot 实例：

* Amazon Linux 2 AMI
* 2 个实例作为目标容量（在任何给定时间点），每个实例有 2 个 vCPU 和 3 GiB RAM

B. 使用 Amazon 创建单个 Spot 实例 Linux 2 和 t2.micro
