## AWS EC2 - 弹性网络接口

<a name="requirements"></a>
### 要求

* 一个带有网络接口的 EC2 实例

<a name="objectives"></a>
### 目标

A. 创建一个网络接口并将其附加到 EC2 已具有一个网络接口的实例
B. 解释为什么有人会使用两个网络接口

<a name="solution"></a>
### 解决方案

A.
1. Go 到 EC2 服务
2. 单击“网络和安全”下的“网络接口”
3. 点击“创建网络接口”
4. 提供描述
5. 选择一个子网（位于 AZ 作为实例）
6. （可选）附加安全组并单击“创建网络接口”
7. 单击“操作”->“附加”并选择要将其附加到的实例
8. 如果您现在转到“实例”页面，您将看到您的实例有两个网络接口

b.
1. 您可以在实例之间移动第二个网络接口。这允许我们在实例之间创建一种故障转移机制。
