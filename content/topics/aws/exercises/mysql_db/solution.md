## AWS 数据库 - MySQL DB

<a name="objectives"></a>
### 目标

1. 创建一个 MySQL 具有以下属性的数据库
  * 实例类型：db.t2.micro
  * GP2存储
  * 应启用存储Auto Scaling并将阈值设置为 500 GiB
  * 应启用公共访问
  * 端口应设置为 3306
  * DB 名称：'db'
  * 备份保留：10天

2. 为您创建的数据库创建只读副本

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 RDS 服务
2. 单击左侧菜单中的“数据库”，然后单击“创建数据库”按钮
3. 选择“标准创建”
4. 选择“MySQL”以及推荐版本
5. 选择“生产”模板
6. 指定 DB 实例标识符
7. 指定凭据（主用户名和密码）
8. 选择 DB 实例类型：Burstable 类，db.t2.micro
9. 选择“gp2”作为存储
10. 启用存储Auto Scaling：最大存储阈值 500 GiB
11. 选择“不创建备用实例”
12. 选择默认值 VPC 和子网
12. 勾选“是”以进行公共访问
13. 选择“无偏好” AZ
14. 数据库端口应该是3306
15. 对于身份验证，选择“密码和 IAM 数据库验证”
16. 将初始数据库名称设置为“db”
17. 将备份保留期增加至 10 天
18. 单击“创建数据库”按钮

1. Go 到左侧菜单中“数据库”下的数据库
2. 单击“操作”-> 创建只读副本
3. 单击“创建只读副本”
