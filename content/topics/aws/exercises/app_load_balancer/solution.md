## AWS ELB - Application Load Balancer 

<a name="requirements"></a>
### 要求

两个 EC2 具有简单 Web 应用程序的实例，该应用程序显示带有字符串“嘿，这是我， `<HOSTNAME>`!"

<a name="objectives"></a>
### 目标

1. 为您拥有的两个实例创建一个应用程序负载均衡器，具有以下属性
  1. 健康阈值：3
  2. 不健康阈值：3
  3. 间隔：10秒
2. 验证负载均衡器是否正常工作（=您在不同时间从两个实例获得回复）

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 EC2 服务
2. 单击左侧菜单中“负载平衡”下的“负载平衡器”
3. 点击“创建负载均衡器”
4. 选择“应用程序负载均衡器”
5. 插入名称 LB
6. 选择一个 AZ 你想要的地方 LB 进行操作
7. 选择安全组
8. 在“侦听器和路由”下，单击“创建目标组”并选择“实例”
  1. 提供目标组的名称
  2. 将健康阈值设置为 3
  3. 将不健康阈值设置为 3
  4. 将间隔设置为 10 秒
  5. 单击“下一步”并选择您创建的两个实例
  6. 点击“创建目标组”
9. 刷新目标组并选择您刚刚创建的目标组
10. 单击“创建负载均衡器”并等待其配置
11. 复制 DNS 地址并将其粘贴到浏览器中。如果刷新，您应该会看到基于流量路由到的实例的不同消息
