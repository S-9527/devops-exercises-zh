## AWS EC2 - EBS 体积创建

<a name="requirements"></a>
### 要求

一 EC2 您可以摆脱的实例:)

<a name="objectives"></a>
### 目标

1. 在同一个目录下创建一个卷 AZ 作为您的实例，具有以下属性：
  1. gp2 卷类型
  2. 4 GiB 大小
2. 创建后，将其附加到您的 EC2 实例
3. 删除你的 EC2 实例。发生了什么事 EBS 附卷 EC2 实例？

<a name="solution"></a>
### 解决方案

1. Go 到 EC2 服务
2. 单击“弹性块存储”下的“卷”
3. 点击“创建卷”
4. 选择以下属性 
  1. gp2 卷类型
  2. 4 GiB 大小
  3. 一样的 AZ 作为你的实例
5. 单击“创建卷”
6. 右键单击您刚刚创建的卷 -> 附加卷 -> 选择您的 EC2 实例并单击“附加”
7. 终止您的实例
8. 默认 EBS 卷（首次启动实例时创建的）将被删除（除非您没有选中“终止时删除”），但您在本练习中创建的卷将保留

注意：不要忘记删除 EBS 您在本练习中创建的体积
