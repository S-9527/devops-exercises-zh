## AWS - Budget Setup

<a name="objectives"></a>
### 目标

制定成本预算 AWS 根据您的需要开设帐户。

<a name="solution"></a>
### 解决方案

1. Go 到“账单”
2. 点击菜单中的“预算”
3. 点击“创建预算”
4. 选择“成本预算”并点击“下一步”
5. 选择适合您的价值观。例如，具有特定金额的经常性每月预算
6. 输入预算名称并单击“下一步” 
7. 设置警报，但单击“添加警报阈值”
  1. 设置阈值（例如预算金额的 75%）
  2. 设置发送通知的电子邮件
8. 单击“下一步”，直到可以单击“创建预算”
