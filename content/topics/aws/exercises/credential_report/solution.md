## AWS - Credential Report

<a name="objectives"></a>
### 目标

1. 创建/下载证书报告
2. 根据报告回答下列问题：
  1. 是否有用户使用 MFA 没有激活？
  2. 是否有启用密码但没有启用的用户 
3. 解释使用证书报告的用例

<a name="solution"></a>
### 解决方案

1. Go 到 AWS IAM 服务
2. 在“访问报告”下单击“凭据报告”
3. 点击“下载报告”并在下载后将其打开
4. 通过检查报告来回答本练习中的问题

凭证报告可用于确定是否有任何用户在安全方面需要帮助或关注。例如用户长期未修改密码且未激活 MFA.
