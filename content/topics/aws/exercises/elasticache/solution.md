## AWS 弹性缓存

<a name="objectives"></a>
### 目标

1. 创建 ElastiCache Redis
  * 实例类型应为“cache.t2.micro”
  * 副本数应为 0

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 至 ElastiCache 服务
2. 点击“立即开始”
3. 选择“Redis"
4. 插入名称和描述
5. 选择“cache.t2.micro”节点类型
6. 将副本数设置为 0
7. 创建新的子网组
8. 点击“创建”
