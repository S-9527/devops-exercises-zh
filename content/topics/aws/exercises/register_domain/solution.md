## AWS Route 53 - Register Domain

<a name="objectives"></a>
### 目标

注意：注册域名需要花钱。不要进行此练习，除非您明白您将要注册域名并且这会花费您金钱。

1. 使用注册您自己的自定义域 AWS Route 53
2. 您的域名是什么类型？
3. 您的域有多少条记录？

<a name="solution"></a>
### 解决方案

1. Go 到 Route 53 服务页面
2. 单击菜单中“域名”下的“注册域名”
3. 点击“注册域名”
4. 插入您的域名
5. 检查是否可用。如果是，请将其添加到购物车 

注意：注册域名需要花钱。不要点击“继续”，除非您明白您将要注册域名并且这会花费您金钱。

6. 点击“继续”并填写您的联系信息
7. 选择将来是否要自动续订。接受条款并点击“完成订单”
8. Go 到托管区域，您应该在那里看到您新注册的域名

1. 域名类型为“公共”

1. 该域有 2 DNS 记录： NS 和 SOA
