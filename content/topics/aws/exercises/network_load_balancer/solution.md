## AWS ELB - 网络负载均衡器

<a name="requirements"></a>
### 要求                   

两人奔跑 EC2 实例

<a name="objectives"></a>
### 目标

1. 创建网络负载均衡器 
  1. 健康阈值：3
  2. 不健康阈值：3
  3. 间隔：10秒
  4. 听众应该使用 TCP 端口 80 上的协议

<a name="solution"></a>
### 解决方案

<a name="console"></a>
#### 控制台

1. Go 到 EC2 服务
2. 单击左侧菜单中“负载平衡”下的“负载平衡器”
3. 点击“创建负载均衡器”
4. 选择“网络负载均衡器”
5. 插入名称 LB
6. 选择您想要的 AZ LB 进行操作
7. 选择安全组
8. 在“侦听器和路由”下，单击“创建目标组”并选择“实例”
  1. 提供目标组的名称
  2. 将健康阈值设置为 3
  3. 将不健康阈值设置为 3
  4. 将间隔设置为 10 秒
  5. 将协议设置为 TCP 并端口到80
  6. 单击“下一步”并选择您拥有的两个实例
  7. 点击“创建目标组”
9. 刷新目标组并选择您刚刚创建的目标组
10. 单击“创建负载均衡器”并等待其配置
