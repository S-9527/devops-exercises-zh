# 分享镜像

<a name="requirements"></a>
## 要求

本地至少有一个镜像（运行 `podman image ls` 来确认）。<br>
如果本地没有镜像，只需运行 `podman pull httpd`.

<a name="objectives"></a>
## 目标

1. 选择一个镜像并从中创建一个存档
2. 检查存档大小。与镜像尺寸不同吗？如果是，有什么区别？如果没有，为什么？
3. 将生成的存档复制到远程主机 
4. 加载镜像
5. 验证它已加载并存在于远程主机上
