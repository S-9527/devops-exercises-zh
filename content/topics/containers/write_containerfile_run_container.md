# 写一个 Containerfile 并运行一个容器

<a name="objectives"></a>
## 目标

1. 创建镜像：
  * 使用centos或ubuntu作为基础镜像
  * 安装 apache 网络服务器
  * 部署您想要的任何 Web 应用程序
  * 添加 https 支持（使用 HAProxy 作为反向代理）
2. 一旦你写了 Containerfile 并创建一个镜像，运行容器并测试应用程序。描述你是如何测试它并提供输出的
3. 描述你的一个或多个弱点 Containerfile。它准备好用于生产了吗？
